# MealSwipe — руководство пользователя

*[English version →](../../README.md)*

**MealSwipe** — self-hosted веб-приложение для планирования питания: свайпы по
карточкам блюд (как в Tinder), автоматическое меню на неделю и единый список
покупок. Интерфейс — на русском языке.

## Что умеет

- **Свайпы**: вправо — нравится, влево — нет; работает мышью, пальцем,
  кнопками и клавиатурой (←/→, `u` — отмена, `i` — подробности).
- **Настройки питания**: сколько человек, сколько приёмов пищи в день, бюджет,
  лимит времени, тип диеты, аллергены и исключённые продукты.
- **Избранное**: закладки понравившихся блюд с поиском и фильтрами.
- **Меню на неделю**: генератор учитывает лайки, аллергены, исключения, тип
  приёма пищи, время готовки, бюджет и разнообразие. Блюдо в слоте можно
  заменить, закрепить или убрать; порции меняются.
- **Список покупок**: ингредиенты суммируются с пересчётом порций и нормализацией
  единиц (г+кг, мл+ст.ложки), группируются по категориям; позиции отмечаются,
  редактируются, добавляются вручную; «уже есть дома» исключает продукт.
- **Общая кухня**: партнёр вступает по коду приглашения — избранное, меню,
  список и запасы становятся общими. Аллергены и исключения объединяются,
  дизлайк любого участника — вето, лайки суммируются.
- **Аккаунты**: логин + пароль (без почты — приложение для локального
  использования), сессии в cookie с защитой CSRF.

## Быстрый запуск (Docker)

Нужны только Docker и Compose v2.

```bash
git clone https://github.com/alexisvaleev/MealSwipe.git
cd MealSwipe
cp .env.example .env
# обязательно задайте POSTGRES_PASSWORD в .env

docker compose up -d --build
curl -fsS localhost:8080/api/v1/health   # {"status":"ok",...}
```

Откройте **http://localhost:8080**, зарегистрируйтесь и начните свайпать.
Миграции и начальный набор рецептов применяются автоматически.
